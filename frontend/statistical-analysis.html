04

Six-hour IST cycle

Evening was the busiest period

—

Why it mattered: The target was built as four IST-aligned six-hour windows instead of a daily total, preserving the strong within-day signal.

Period definition

Night, morning, afternoon, and evening are fixed six-hour IST periods. The matrix separates each period by meteorological season.
