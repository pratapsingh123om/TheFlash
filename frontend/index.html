How to read this map

Colours are based on probability thresholds frozen on the 2022 validation period. A coloured cell is a regional warning location, not a predicted individual strike point.

Input contract

The backend expects four consecutive six-hour feature grids. Each must contain independently prepared weather predictors and the exact feature schema stored with the model.

Recommended use

Use the first six-hour interval as the primary result. The later intervals demonstrate recursive behaviour and should be communicated with increasing uncertainty.
